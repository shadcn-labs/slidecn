## Usage

```tsx

import { ProductDemo } from "@/components/slides/blocks/product-demo";

  return (
    <Deck>
      <ProductDemo />
    </Deck>
  );
}
```

## Slides

1. **Title** — Product name and tagline
2. **Features** — Animated feature list
3. **Screenshot** — Full-bleed product image
4. **Comparison** — Table comparison vs competitors
5. **Metrics** — Trust metrics row
6. **CTA** — Call to action
