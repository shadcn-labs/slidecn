## Prerequisites

Before using slidecn components, make sure you have:

- A React project (Next.js, Remix, Vite, etc.)
- [shadcn/ui](https://ui.shadcn.com) installed

## Installing Components

To install a slidecn component:

```bash
npx shadcn@latest add https://slidecn.dev/r/component-name.json
```

## Development Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Aniket-508/slidecn.git
cd slidecn
```

### 2. Install Dependencies

```bash
pnpm install
```

### 3. Start Development Server

```bash
pnpm dev
```

### 4. Build for Production

```bash
pnpm build
```

## Project Structure

```
├── registry/                 # Component registry files
│   └── new-york/            # Registry components
├── content/docs/             # Documentation (MDX)
├── app/                     # Next.js app
├── public/r/                # Built registry files (auto-generated)
└── components/              # UI components
```

## Adding New Components

To add new presentation components:

1. Create component in `registry/slidecn/ui/`
2. Update `registry.json` with component details
3. Run `pnpm registry:build`
